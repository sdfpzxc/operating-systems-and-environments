# Здесь будут храниться теоретические материалы

**Чему научились на уроках:**

На уроках изучили фундаментальные основы устройства операционных систем. Разобрали историю, назначение и виды ОС, структуру ядра и процесс загрузки системы. Отдельно рассмотрели модель процесса, потоки исполнения и механизмы межпроцессного взаимодействия. Кроме того, освоили принципы организации памяти и научились работать с теоретическими материалами (презентациями), закрепляя знания по темам курса.
