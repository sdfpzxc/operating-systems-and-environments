## Шаг 0. Что нужно понять заранее

Ubuntu Satanic Edition (USE) — это **кастомная сборка на базе Ubuntu 10.10 (Maverick Meerkat), выпущенная в 2010 году**. Она включает тёмную тему, обои с сатанинской символикой, изменённые звуки и набор предустановленного ПО.

Это значит:
- Дистрибутив **снят с поддержки** — обновления безопасности не выходят.
- Ядро старое (2.6.35), поэтому возможны конфликты с современным железом.
- В VirtualBox он запускается, но **требует 32-битной версии** и отключённого EFI.
- Никакого UEFI, Secure Boot и прочих современных вещей там нет.

Для виртуальной машины это идеальный вариант — вы не рискуете основной системой.

---

## Шаг 1. Скачивание ISO-образа

### Где искать
Официальный сайт `ubuntusatanic.org` давно мёртв. Образы сохранились в архивах:

1. **Internet Archive** — поиск по запросу `Ubuntu Satanic Edition`. Там лежат версии 666.4 и 666.10.
2. **LinuxTracker** — торрент-трекер, где выложены как i386, так и amd64 версии.
3. **old-releases.ubuntu.com** — там базовой USE нет, но есть оригинальная Ubuntu 10.10, если захотите собрать тему вручную.

### Какой файл брать
Ищите файл с именем вроде:
```
satanic-edition-666.10-desktop-i386.iso
```
**Берите i386 (32-bit)**. Причина: 64-битные сборки USE, по отзывам на форумах VirtualBox, часто не стартуют даже при включённой аппаратной виртуализации.

### Проверка целостности
Если рядом с ISO есть файл `.md5` или `.sha1` — скачайте и проверьте. В Linux:
```bash
md5sum satanic-edition-666.10-desktop-i386.iso
```
В Windows можно использовать `certutil -hashfile <файл> MD5`.

## Шаг 2. Установка VirtualBox

Если VirtualBox ещё не установлен:

- **Windows/macOS:** скачайте с `virtualbox.org/wiki/Downloads`.
- **Linux:** `sudo apt install virtualbox` (Debian/Ubuntu) или через менеджер пакетов вашего дистрибутива.

Также рекомендую поставить **Extension Pack** — он добавляет поддержку USB 2.0/3.0, RDP и шифрования диска. Для USE это не критично, но пригодится.

## Шаг 3. Создание виртуальной машины

Откройте VirtualBox → **Машина → Создать** (или кнопка «Создать»).

### 3.1. Имя и тип ОС
- **Имя:** `Ubuntu Satanic Edition` (любое).
- **Папка:** оставьте по умолчанию или выберите место с достаточным объёмом.
- **Тип:** `Linux`.
- **Версия:** `Ubuntu (32-bit)`.
- **ISO-образ:** сразу укажите скачанный файл (галочка «Пропустить автоматическую установку» должна быть **включена**, иначе VirtualBox попытается применить unattended-установку, которая со старым дистрибутивом не сработает).

### 3.2. Железо
- **ОЗУ:** 1024–2048 МБ. Меньше 1 ГБ — будет тормозить; больше 2 ГБ — бессмысленно для 32-битной системы.
- **Процессор:** 1 ядро достаточно. 2 ядра — комфортнее, но USE не оптимизирован под SMP.
- **Жёсткий диск:**
  - Выберите «Создать новый виртуальный жёсткий диск».
  - Тип: **VDI**.
  - Формат: **Динамически выделяемый** (экономит место).
  - Размер: **15 ГБ** (хватит с запасом; сама система займёт ~4–5 ГБ).

### 3.3. Настройки после создания
Выделите VM → **Настроить**.

**Система → Материнская плата:**
- Чипсет: **PIIX3** (не ICH9 — он иногда ломает загрузку старых ядер).
- **Снимите галочку «Включить EFI»** — это критично.
- Порядок загрузки: **Оптический привод → Жёсткий диск**.
- «Включить IO APIC» — можно оставить включённым.
- «Включить абсолютный указатель мыши» — **включите**, иначе курсор будет «убегать».

**Система → Процессор:**
- **Включите PAE/NX** — Ubuntu 10.10 требует PAE для работы.
- **Включите VT-x/AMD-V** и «Вложенную виртуализацию», если доступны.

**Дисплей:**
- Видеопамять: **32–64 МБ**.
- Графический контроллер: **VMSVGA** (для старых Linux работает стабильнее, чем VBoxSVGA).
- **Выключите 3D-ускорение** — старые драйверы Mesa с ним конфликтуют.

**Носители:**
- Убедитесь, что ISO подключён к IDE-контроллеру (не SATA — SATA в старых ядрах иногда не определяется без правки конфигов).
- Если ISO не подключён — нажмите на иконку диска → «Выбрать файл образа оптического диска…».

**Сеть:**
- Тип подключения: **NAT** (проще всего) или **Мост** (если хотите, чтобы VM была видна в локальной сети).

**Общие папки** (опционально):
- Можно добавить позже, после установки Guest Additions.

## Шаг 4. Запуск и установка

Нажмите **Запустить**.

### 4.1. Меню загрузки
Появится меню Ubuntu 10.10. Выберите:
- **«Установить Ubuntu»** — для прямой установки.
- Или **«Запустить Ubuntu без установки»** — Live-режим, чтобы сначала проверить, что всё работает.

Если меню не появляется и вы видите чёрный экран или ошибку `FATAL: No bootable medium found` — проверьте, что ISO подключён и порядок загрузки правильный.

### 4.2. Установка
Процесс стандартный для Ubuntu того времени:

1. **Язык** — выберите русский или английский.
2. **Подготовка к установке** — подключение к сети (можно пропустить), установка стороннего ПО (можно пропустить).
3. **Разметка диска:**
   - Выберите **«Стереть диск и установить Ubuntu»** — это виртуальный диск, данные терять не страшно.
   - Или вручную: `/` — ext4, ~14 ГБ; `swap` — ~1 ГБ.
4. **Часовой пояс** — выберите свой.
5. **Раскладка клавиатуры** — обычно `Russian` + `English (US)`.
6. **Имя пользователя, логин, пароль** — заполните.
7. **Установка** — займёт 10–20 минут в зависимости от скорости диска.

### 4.3. После установки
VirtualBox предложит перезагрузиться. Нажмите **«Перезагрузить сейчас»**. Когда VM начнёт выключаться, **отключите ISO** через меню устройств (или заранее в настройках носителей), иначе система снова загрузится с установщика.

## Шаг 5. Первый запуск и базовая настройка

После загрузки вы увидите тёмную тему USE, обои с пентаграммой и изменённый экран входа.

### 5.1. Установка Guest Additions
Это нужно для:
- Общего буфера обмена.
- Drag-and-drop файлов.
- Автоматического изменения разрешения экрана.
- Общих папок.

Порядок:
1. В меню VM: **Устройства → Подключить образ диска Дополнений гостевой ОС**.
2. Внутри USE откройте терминал.
3. Выполните:
   ```bash
   sudo apt-get update
   sudo apt-get install build-essential linux-headers-$(uname -r) dkms
   sudo mount /dev/cdrom /mnt
   cd /mnt
   sudo ./VBoxLinuxAdditions.run
   ```
4. Перезагрузитесь.

**Важно:** для Ubuntu 10.10 репозитории `archive.ubuntu.com` уже не работают. Нужно заменить их на `old-releases.ubuntu.com`:
```bash
sudo sed -i 's/archive.ubuntu.com/old-releases.ubuntu.com/g' /etc/apt/sources.list
sudo sed -i 's/security.ubuntu.com/old-releases.ubuntu.com/g' /etc/apt/sources.list
sudo apt-get update
```

### 5.2. Настройка разрешения экрана
Если после установки Guest Additions разрешение не подстраивается автоматически:
- **Система → Параметры → Мониторы** — выберите нужное вручную.
- Или в терминале: `xrandr --output VGA-0 --mode 1280x800` (имя выхода может отличаться — посмотрите `xrandr` без аргументов).

### 5.3. Общие папки
1. В настройках VM: **Общие папки → Добавить**.
2. Укажите путь на хосте, имя папки (например, `share`), включите «Автоподключение» и «Постоянно».
3. Внутри USE:
   ```bash
   sudo mkdir /media/share
   sudo mount -t vboxsf share /media/share
   ```
   Для автомонтирования добавьте строку в `/etc/fstab`:
   ```
   share /media/share vboxsf defaults 0 0
   ```

## Шаг 6. Что делать, если что-то не работает

### Система не загружается с ISO
- Проверьте, что **EFI выключен**.
- Смените чипсет на **PIIX3**.
- Переключите ISO с SATA на **IDE**.
- Включите **PAE/NX**.

### Чёрный экран после установки
- Загрузитесь в recovery mode (удерживайте Shift при старте).
- Восстановите GRUB: `sudo update-grub`.
- Или переустановите GRUB: `sudo grub-install /dev/sda`.

### Не работает мышь
- Включите **«Абсолютный указатель мыши»** в настройках системы VM.

### Не работает сеть
- Проверьте, что в VM включён NAT.
- Внутри USE: `sudo dhclient eth0`.
- Если не помогло — в настройках VM смените тип адаптера с `Intel PRO/1000` на `PCnet-FAST III` (старое ядро лучше дружит с ним).

### Не устанавливаются Guest Additions
- Убедитесь, что установлены `build-essential`, `linux-headers` и `dkms`.
- Если репозитории недоступны — замените их на `old-releases.ubuntu.com` (см. выше).
- Для очень старых версий VirtualBox может потребоваться версия Guest Additions **5.x**, а не 7.x. Их можно скачать с `download.virtualbox.org/virtualbox/`.

### Система тормозит
- Уменьшите разрешение экрана.
- Отключите визуальные эффекты: **Система → Параметры → Внешний вид → Визуальные эффекты → Нет**.
- Выделите 2 ГБ ОЗУ и 2 ядра.
