# Создание снимко в Виртуальной машине

## Описание
Домашнее задание по дисциплине "Операционные системы и среды". Цель работы — освоить механизм снимков (snapshots) виртуальной машины в Oracle VirtualBox: сохранять состояние системы, имитировать "поломку" 
и откатываться к рабочему состоянию. 

**Задание для дз:**

Создать снимок (snapshot) состояния виртуальной машины и прикрепить подтверждающий скриншот.

**Выполнение работы:**

| № | Шаг |
|---|-----|
| 1 | Скачать и установить VirtualBox |
| 2 | Скачать `Learning Debian.ova` и импортировать его в VirtualBox |
| 3 | Полностью завершить сеанс ВМ, перейти во вкладку "Снимки", нажать "Сделать" |
| 4 | Задать имя снимка (например, `deb1`) и описание, сохранить |
| 5 | Запустить ВМ, войти как root |
| 6 | Выполнить "патч Бармина" — команду удаления системы: `rm -rf --no-preserve-root /` |
| 7 | Принудительно выключить ВМ, запустить снова (ожидается `kernel panic`) |
| 8 | Откатиться: выбрать снимок, нажать "Восстановить" |
| 9 | Запустить ВМ — система работает как до "поломки" |

**Требования к отчёту**
- Оформляется в Word/PDF.
- Каждый шаг фиксируется (скриншоты и описание).
- В конце — вывод: какие знания извлечены из ДЗ, какие результаты получены.

**Чему научились на уроке:**

На уроке изучили принципы работы с виртуальными машинами и понятие снимков состояния (snapshots). На практике научились создавать снимки в гипервизоре (VirtualBox), чтобы сохранять текущее состояние ОС и данных перед внесением изменений, а также освоили навык восстановления системы из сохраненной точки при необходимости.
