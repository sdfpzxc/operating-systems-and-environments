# Operating systems and environments

## Это репозиторий по дисциплине Операционные системы и среды

Курс учит понимать, как устроена операционная система изнутри, и осваивать базовые принципы управления ее ресурсами. В целом он дает базу для того, чтобы разбираться в архитектуре ОС, уметь работать с процессами, потоками и памятью, а также понимать, как обеспечивается безопасность и взаимодействие программ.
