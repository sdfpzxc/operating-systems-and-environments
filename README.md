# Здесь будут находиться заданные выполненные презентации на определенную тему

Подготовить и загрузить презентации по заданным темам, а также приложить инструкцию по установке.

**Чему научились:**

На уроке изучили процесс установки и настройки операционных систем семейства Linux (на примере Ubuntu Satanic Edition). На практике научились оформлять техническую информацию в виде презентаций, структурировать материал и составлять пошаговые инструкции (гайды) по установке программного обеспечения.
