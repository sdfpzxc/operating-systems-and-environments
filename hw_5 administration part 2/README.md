# Администрирование 2 часть

## Описание
Домашнее задание по дисциплине "Операционные системы и среды". Цель работы — научиться настраивать сетевой адаптер виртуальной машины, назначать IP-адрес и проверять связь между гостем и хостом с помощью команд `ip` и `ping`. Работа выполняется в VirtualBox на гостевой ОС Debian/Ubuntu Server.


**Задание для дз:**

Выполнить практические задания из файла «Администрирование 2: возвращение сети» на виртуальной машине. Настроить сетевые адаптеры и проверить связь с помощью команд `ip` и `ping`.

**Выполнение работы:**

| № | Задание | Команда / действие |
|---|---------|--------------------|
| 1 | Подключить второй адаптер: тип "Виртуальный адаптер", имя `VirtualBox Host-Only Ethernet Adapter`, включить кабель | Настройки ВМ -> Сеть -> Адаптер 2 |
| 2 | Получить информацию о сетевых интерфейсах | `ip address` |
| 3 | Назначить третьему адаптеру незанятый IP из сети `192.168.56.0` | `ip address add 192.168.56.3 dev enp0s8` |
| 4 | Проверить связь с самим собой (свой новый адрес) | `ping 192.168.56.3` |
| 5 | Проверить связь с хост-машиной | `ping 192.168.56.1` |
| 6 | Проверить связь из хост-машины в гостевую | В Windows: `ping 192.168.56.3` |

**Требования к отчёту:**

- Оформляется в Word/PDF.
- Каждый шаг фиксируется: команда + скриншот вывода.

**Чему научились на уроке:**

На уроке изучили принципы работы с сетевыми интерфейсами в Linux. На практике научились добавлять второй сетевой адаптер в настройках VirtualBox (тип «Виртуальный адаптер»), получать информацию о сетевых устройствах с помощью команды `ip address` (разбирать вывод: MAC-адреса, IPv4/IPv6, интерфейсы `lo`, `enp0s3`, `enp0s8`), а также вручную задавать IP-адрес на адаптере командой `ip address add`. Освоили проверку сетевой связности с помощью утилиты `ping` (проверка себя, хост-машины и гостевой машины из Windows).
