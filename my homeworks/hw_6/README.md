# Практика по демонам

**Задание для дз:**

Выполнить практические задания из файла «Создание демонов» на виртуальной машине. Создать Bash-скрипт, который периодически пишет в syslog сообщения о своей активности и обрабатывает сигналы завершения (SIGTERM, SIGINT). Настроить запуск программы как пользовательского и системного демона через systemd.

**Чему научились на уроке:**

На уроке изучили понятие демонов (фоновых сервисов) в Unix-подобных ОС и принципы управления ими через `systemd`. На практике научились писать Bash-скрипт для записи в системный журнал с помощью `logger`, обрабатывать сигналы завершения через `trap` и использовать задержки `sleep`. Освоили создание конфигурационных файлов служб (`.service`) в `~/.config/systemd/user/` для пользовательских демонов и в `/etc/systemd/system/` для системных, а также команды управления: `systemctl daemon-reload`, `start`, `stop`, `status`, `enable`, `disable`. Научились проверять работу демона по записям в `/var/log/syslog` и настраивать автоматический запуск при загрузке системы.
