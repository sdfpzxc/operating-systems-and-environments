# Простые команды 2 часть

**Задание для дз:**

Выполнить практические задания из файла «Использование простых команд 2: Bash наносит ответный удар» на виртуальной машине. Отработать команды взаимодействия с файловой системой и использование потоков.

**Чему научились на уроке:**

На уроке продолжили изучать базовые команды Bash и работу с файловой системой. На практике научились создавать новые каталоги и пустые файлы (`touch`), переходить между директориями и определять текущее местоположение (`pwd`). Освоили запись текста в файл с помощью `echo` (включая построчную запись), переименование файлов, а также чтение и проверку их содержимого. Кроме того, научились искать нужные строки с помощью `grep`, перенаправлять вывод в новый файл, объединять файлы и подсчитывать количество вхождений символов с помощью `wc` в связке с `grep`.
