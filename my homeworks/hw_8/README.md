# Практика по ассемблеру

**Задание для дз:**

Выполнить практические задания из файла «Автоматизация сборки Unix Makefiles». Настроить автоматическую сборку программы на языке ассемблера (GASM) с помощью утилиты Make, создав конфигурационный файл `Makefile`.

**Чему научились на уроке:**

На уроке изучили основы работы с языком ассемблера GASM и процесс компиляции программ. На практике научились писать простой исходный код на ассемблере, компилировать его с помощью `as` и компоновать в исполняемый файл с помощью `ld`. Освоили утилиту автоматизации сборки `make` и синтаксис написания `Makefile`: разобрали понятия целей (targets), зависимостей и команд, научились описывать дерево зависимостей (от исходного `.s` файла к объектному `.o` и исполняемому файлу), использовать абстрактные цели (`clean`, `build`) и директиву `.PHONY`. Теперь сборка программы выполняется одной командой `make build`.
