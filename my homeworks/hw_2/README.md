# Простые команды

**Задание для дз:**

Выполнить практические задания из файла «Использование простых команд» на виртуальной машине с использованием утилит `cd`, `ls`, `cat`, `grep` и `find`.

**Чему научились на уроке:**

На уроке изучили базовые команды работы с файловой системой в командной оболочке Linux. На практике освоили навигацию по каталогам с помощью `cd` и просмотр их содержимого через `ls` (включая сортировку по размеру). Научились выводить содержимое файлов командой `cat`, искать нужные строки в тексте с помощью `grep` (в том числе исключая комментарии) и использовать мощный инструмент поиска `find` для фильтрации файлов по расширению, типу (ссылки, каталоги), владельцу и глубине вложенности, а также для выполнения команд над найденными файлами через `-exec`.
