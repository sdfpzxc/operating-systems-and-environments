# Администрирование 2 часть

**Задание для дз:**

Выполнить практические задания из файла «Администрирование 2: возвращение сети» на виртуальной машине. Настроить сетевые адаптеры и проверить связь с помощью команд `ip` и `ping`.

**Чему научились на уроке:**

На уроке изучили принципы работы с сетевыми интерфейсами в Linux. На практике научились добавлять второй сетевой адаптер в настройках VirtualBox (тип «Виртуальный адаптер»), получать информацию о сетевых устройствах с помощью команды `ip address` (разбирать вывод: MAC-адреса, IPv4/IPv6, интерфейсы `lo`, `enp0s3`, `enp0s8`), а также вручную задавать IP-адрес на адаптере командой `ip address add`. Освоили проверку сетевой связности с помощью утилиты `ping` (проверка себя, хост-машины и гостевой машины из Windows).
