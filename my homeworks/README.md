# Здесь будут находится выполненные домашние задания

Закрепление практических навыков работы с операционной системой Linux (Ubuntu Server). А также освоение базовых и продвинутых команд Bash: навигацию по файловой системе, работу с текстовыми потоками и фильтрами (`cat`, `grep`, `find`), управление процессами (`ps`, `top`, `man`), настройку сетевых интерфейсов (`ip`, `ping`), а также написание скриптов с использованием функций и создание системных служб (демонов) через `systemd`. Кроме того, научились автоматизировать сборку программ на ассемблере с помощью `Makefile`.
