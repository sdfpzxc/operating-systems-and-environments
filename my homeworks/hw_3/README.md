# Администрирование

**Задание для дз:**

Выполнить практические задания из файла «Администрирование» на виртуальной машине. Отработать команды взаимодействия с процессами и изучить справочную информацию с помощью утилиты `man`.

**Чему научились на уроке:**

На уроке изучили методы управления процессами в Linux. На практике научились отображать процессы в виде дерева (с иерархией родительских и дочерних процессов), фильтровать их по имени пользователя, выводить топ процессов по потреблению памяти, а также находить процессы, работающие в фоновом режиме. Кроме того, освоили работу со справочной системой `man`: научились открывать страницы справки, искать нужные аргументы команд (например, для сохранения прав при копировании) и искать справки по ключевым словам с помощью `apropos` и `man -k`.
