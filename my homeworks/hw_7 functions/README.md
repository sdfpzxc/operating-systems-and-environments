# Практика по функциям

## Описание
Домашнее задание по дисциплине "Операционные системы и среды". Цель работы — освоить создание и использование функций в Bash: передача аргументов, локальные переменные, код возврата, перенаправление вывода, команда `eval`. Работа выполняется в гостевой ОС Debian (VirtualBox), в терминале.


**Задание для дз:**

Выполнить практические задания из файла «Функции в Bash» на виртуальной машине. Написать Bash-скрипты с использованием функций: вывод текста в заданный поток, вывод информации о системе по запросу, вывод значения переменной по её имени через `eval`. Также ответить на вопрос об отличии `exit` и `return`.

**Выполнение работы:**

| № | Задание | Команда |
|---|---------|---------|
| 1 | Создать скрипт для вывода в заданный поток | `touch task1.sh` |
| 2 | Написать функцию с проверкой аргумента (`stdout`, `stderr`, файл) | см. листинг `task1.sh` |
| 3 | Дать права на выполнение и запустить скрипт | `chmod +x task1.sh`; `./task1.sh` |
| 4 | Создать скрипт для вывода системной информации | `touch task2.sh` |
| 5 | Написать функцию с `case` для параметров `pwd`, `user`, `version` | см. листинг `task2.sh` |
| 6 | Дать права и запустить второй скрипт | `chmod +x task2.sh`; `./task2.sh` |
| 7 | Создать скрипт для вывода переменной по имени через `eval` | `touch task3.sh` |
| 8 | Написать функцию и цикл `while read` до `Ctrl+D` | см. листинг `task3.sh` |
| 9 | Дать права и запустить третий скрипт | `chmod +x task3.sh`; `./task3.sh` |

**Требования к отчёту:**
- Оформляется в Word/PDF.
- Каждый шаг фиксируется: код + скриншот выполнения.
- В конце — вывод: какие знания извлечены, какие приёмы работы с функциями освоены.

**Чему научились на уроке:**

На уроке изучили синтаксис и принципы использования функций в Bash. На практике научились объявлять функции без указания аргументов в скобках, передавать аргументы через `$1`, `$2` и т.д., использовать локальные переменные через `local` и возвращать код завершения с помощью `return`. Разобрали отличие команды `exit` (завершает работу всего скрипта или оболочки) от `return` (завершает только выполнение функции и возвращает код). Написали функции для перенаправления вывода в stdout, stderr или файл, для вывода информации о системе по ключевому слову (pwd, user, version) и для получения значения переменной по её имени с использованием команды `eval` в цикле до EOF (Ctrl+D).
