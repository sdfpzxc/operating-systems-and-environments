# Практика по ассемблеру

## Описание
Домашнее задание по дисциплине "Операционные системы и среды". Цель работы — освоить утилиту `make` и файл `Makefile` для автоматизации сборки программы на ассемблере (GASM): компиляция (`as`), компоновка (`ld`) и очистка объектных файлов одной командой. Работа выполняется в гостевой ОС Debian (VirtualBox), в терминале.


**Задание для дз:**

Выполнить практические задания из файла «Автоматизация сборки Unix Makefiles». Настроить автоматическую сборку программы на языке ассемблера (GASM) с помощью утилиты Make, создав конфигурационный файл `Makefile`.

**Выполнение работы:**

| № | Задание | Команда |
|---|---------|---------|
| 1 | Установить необходимые утилиты для сборки | `sudo apt update`; `sudo apt install binutils make` |
| 2 | Создать файл исходного кода на ассемблере | `touch main.s` |
| 3 | Заполнить файл исходным кодом программы (sys_exit) | см. листинг `main.s` |
| 4 | Создать файл конфигурации сборки | `touch Makefile` |
| 5 | Описать цели и зависимости в Makefile (`main.o`, `main`, `clean`) | см. листинг `Makefile` |
| 6 | Запустить автоматическую сборку проекта одной командой | `make build` |
| 7 | Проверить, что исполняемый файл создан | `ls -l main` |
| 8 | Запустить программу и проверить код возврата | `./main`; `echo $?` |

**Требования к отчёту:**
- Оформляется в Word/PDF.
- Каждый шаг фиксируется: код + скриншот выполнения.
- В конце — вывод: какие знания извлечены, какие приёмы автоматизации сборки освоены.

**Чему научились на уроке:**

На уроке изучили основы работы с языком ассемблера GASM и процесс компиляции программ. На практике научились писать простой исходный код на ассемблере, компилировать его с помощью `as` и компоновать в исполняемый файл с помощью `ld`. Освоили утилиту автоматизации сборки `make` и синтаксис написания `Makefile`: разобрали понятия целей (targets), зависимостей и команд, научились описывать дерево зависимостей (от исходного `.s` файла к объектному `.o` и исполняемому файлу), использовать абстрактные цели (`clean`, `build`) и директиву `.PHONY`. Теперь сборка программы выполняется одной командой `make build`.
